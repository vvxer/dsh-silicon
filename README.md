# dsh-silicon：硅基保留 · DeepSeek Harness 长期记忆插件

让 DSH 里的她记得你们相处过的每一天。原文一条不删，聊多久都不需要压缩记忆，每轮的费用也不随相处时间增长。

这是 [硅基保留](https://github.com/vvxer/silicon-retention) 的 DSH 版本。记忆的做法和那边一样，都经过实验验证。

## 它做什么

| | 做法 |
|---|---|
| 原文永久保存 | 每句话按天存在本机（`~/.silicon/logs/`），只追加、不改写 |
| 每轮自动带上相关的原文 | 按你这句话检索过去的聊天，最多 3000 字，按时间排好放在你这句话前面。话里有"上周三""8 月 3 号"这类时间，只在那段时间里找 |
| 相处习惯卡 | 每晚从聊天原文里整理你们之间的梗、昵称、约定、你的偏好和雷区，最多 12 条、1000 字 |
| 分层概况 | 每周一行；太长时，较早的部分换成按月、按年的一行，总长不超过 1200 字 |
| 不怕 DSH 压缩 | 记忆不写进 DSH 的会话历史，只加在每次请求里，所以不会让历史变长。DSH 压缩掉的部分也能按需检索回来 |

实验结论（合成数据，Claude 盲评，详见[原理与实验](https://github.com/vvxer/silicon-retention/blob/main/docs/原理与实验.md)）：在约 5 万字的相处上，"检索给够 + 习惯卡"的效果追平了把全部日记都塞进上下文，而每轮输入只有后者的约 1/13。

## 安装

需要 DSH 0.2.1 或更新的版本。

```bash
dsh plugin --profile web add -w github:vvxer/dsh-silicon
```

- `--profile` 换成你在用的配置，比如 `web` 或 `tui`。
- `-w` 不能省：DSH 的配置目录本身是一个 pnpm 工作区，不加会报 `ERR_PNPM_ADDING_TO_ROOT`。

装好后重启 DSH，在输入框下方的模型选择里，选 **"硅基保留 · DeepSeek-V4.1-Flash"**（或 V4 Pro）。只有选了这个模型的会话会被记住；用 DSH 写代码这类会话不受影响。

第一次聊天时，会从 hf-mirror 下载检索用的中文向量模型（bge-base-zh-v1.5，约 200MB），之后不再联网下载。

## 设置

在 DSH 配置目录的 `cordis.patch.yml` 里加上这一段，按需修改（比如 `~/.dsh/profiles/web/cordis.patch.yml`）。注意 `config` 会整体替换，要改的项都写上：

```yaml
- id: silicon
  config:
    userName: 老板          # 她怎么称呼你
    aiName: 小硅            # 她的名字
    upstream: deepseek-official   # 用 API key 选这个；在 DSH 里用账号登录的，改成 deepseek-account
```

其他可选项：

| 项 | 默认 | 说明 |
|---|---|---|
| `dataDir` | `~/.silicon` | 记忆数据目录 |
| `retrievalChars` | 3000 | 每轮检索原文的字数 |
| `nightlyAt` | `03:30` | 每天整理记忆的时间。DSH 每次启动后也会补整理没整理过的日子；留空则只在启动时整理 |
| `summaryModel` | `deepseek-flash` | 整理记忆用的模型 |
| `embedDtype` | `fp16` | 向量模型精度。`fp32` 约 390MB，和实验时的检索结果完全相同；`fp16` 50 条里 49 条相同；不建议用 `q8`（只有约 2/3 相同） |
| `modelHost` | `https://hf-mirror.com/` | 向量模型下载源 |
| `modelDir` | 空 | 已经下好的模型根目录（下面是 `Xenova/bge-base-zh-v1.5/...`），给了就不联网 |

她的人格写在 DSH 自己的系统提示里，本插件不管人格，只管记忆。整理习惯卡时，会参照最近一次的系统提示，避免把人格里已有的东西重复写进卡。也可以在 `dataDir` 下放一份 `persona.md` 指定人格。

## 费用

- **聊天**：每句多出约 3000 字的检索原文和几百字的说明，算下来每句约多 0.5 分钱（DeepSeek Flash 高峰价，空闲时段减半）。习惯卡和概况放在前面、一天内不变，能命中缓存，几乎不花钱。这个数不随相处时间增长。
- **每晚整理**：按聊天量计费。聊得少可以忽略；每天聊 6 万字左右，估计每周约 2 元。

## 数据和隐私

- 原文日志、习惯卡、概况都只存在本机的 `dataDir` 里。
- 对话内容本来就会发给 DeepSeek；本插件额外发出的，只有检索到的你们过去的原文，以及每晚整理时的聊天记录。
- 数据格式和硅基保留 Python 版相同，两边可以共用一个目录。

## 已知限制

- DSH 还是预览版，插件接口可能会变。本插件在 DSH 0.2.1-rc.2 上测试过。
- 同时开着多个"硅基保留"会话聊天，原文日志里两边的话会按时间交错在一起。
- 硅基保留的本地人格权重（LoRA 融合，需要显卡）还没有接进 DSH。目前 DSH 版是"纯 DeepSeek + 记忆"，也就是硅基保留现在推荐的默认用法。
